# THK Methodologie & Statistiek

Publieke verzameling van colleges, practica, datasets en vrijgegeven antwoorden
voor methodologie en statistiek binnen Tandheelkunde. Brightspace blijft de
officiële omgeving voor mededelingen, deadlines en cursuswijzigingen.

## Huidige inhoud

- WS2-1, college en practicum 1 (2026-2027)
- collegeslides als PDF
- practicum als Word-bestand
- SPSS-databestand `pockets.sav`

Antwoorden worden pas toegevoegd wanneer ze voor studenten mogen worden
vrijgegeven. Ze staan op de cursuspagina bewust in een afzonderlijke sectie.

## Publiceren met GitHub Pages

De workflow `.github/workflows/deploy-pages.yml` bouwt en publiceert de website
automatisch bij iedere push naar `main`. De workflow kan daarnaast handmatig
worden gestart vanuit het tabblad **Actions**.

Selecteer eenmalig **Settings > Pages > Source > GitHub Actions**. Daarna is geen
handmatige publicatiestap meer nodig.

## Veilig publiceren

Voeg uitsluitend definitieve studentbestanden toe. Publiceer geen bronbestanden,
docentnotities, persoonsgegevens, toetsmateriaal of antwoorden die nog niet zijn
vrijgegeven.
