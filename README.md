# THK onderwijsmaterialen

Publieke back-upomgeving voor studentmaterialen van Tandheelkunde. Brightspace
blijft de officiële cursusomgeving.

## Huidige inhoud

- WS2-1, college en practicum 1 (2026-2027)
- collegeslides als PDF
- practicum als Word-bestand
- SPSS-databestand `pockets.sav`

Antwoorden worden pas toegevoegd wanneer ze voor studenten mogen worden
vrijgegeven. Ze staan op de cursuspagina bewust in een afzonderlijke sectie.

## Publiceren met GitHub Pages

Publiceer de site vanuit de root van de `main`-branch via **Settings > Pages**.
De site gebruikt alleen statische HTML en CSS en heeft geen buildstap nodig.

## Veilig publiceren

Voeg uitsluitend definitieve studentbestanden toe. Publiceer geen bronbestanden,
docentnotities, persoonsgegevens, toetsmateriaal of antwoorden die nog niet zijn
vrijgegeven.
